06工程

Anthropic 用 Claude 把 Messages API 整体重写为 Rust：CPU 降 40–50%

Anthropic 平台工程负责人 Katelyn Lesse 在 Latent Space 播客中透露，团队里没有 Rust 开发者，由人类设计架构和计划、Claude 写出大部分代码，再让新旧两版在真实流量上并行运行、确认输出一致后才切换。结果 CPU 消耗降低 40–50%，首 token 延迟改善 10–20%。不少开发者认为「永远别做大重写」这条老经验正在失效。
