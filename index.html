02模型

开发者热议 Claude Opus 5.5「手感变差」，分析指向 11 月 3 日推理风格突变

多位开发者抱怨 Opus 5.5 近几日更爱幻觉、不听指令、更快打满额度。Shane Melaugh 让 Gemini 4 Argon 分析了约 1400 次 Claude Code 会话，称模型名称没变，但 11 月 3 日前后推理方式明显转向：high 档思考量下滑、更急于动手并顺着错误第一猜测走下去。他另测同一 bug：high 档折腾约 3 小时找不到修复，xhigh 档几分钟就修好。Anthropic 尚未就此公开回应；固定基准测试未必能反映这种体感变化。

03评测

MaxxBench：微调考题后不少模型 DeepSWE 高分大跌，Opus 5.5 不降反升

Justin Lo（@loresjpg）发布 MaxxBench：把 89 道 DeepSWE 任务的说明或起始代码做小改动（例如文件名大小写），看模型会不会跟着改要求。原 DeepSWE 上挤在约 74% 的模型被拉开约 23 个百分点。讨论中常被引用的数字是：Claude Opus 5.5 从 74.2% 升到 76.4%，是对比里少数不降反升的；GPT-6 Astra 约 71.9%；DeepSeek V4.1 Flash 从 74.2% 降到 55.6%；Gemini 3.8 Flash 从 73.8% 降到 53.4%。原帖约 4000 赞、47.9 万浏览。这和「Opus 被削弱」的体感讨论形成对照：固定榜单上它仍更跟得上改过的要求。
